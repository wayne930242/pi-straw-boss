# Automatic membership and promotion (0.4.1)

The user's decisions of 2026-10-17, replacing opt-in joining.

1. Every joinable pi in Herdr joins automatically as a member at session start, with no reminder and no question. Not joinable, unchanged: outside Herdr, pi-herdr-agents subagents (`PI_SUBAGENT_ID`), sessions in sub workspaces (linked worktrees), and the tower itself.
2. Promotion to main: the agent calls the new tool `boss_promote` when its work grows (several steps, dispatching workers, more than one app); the member prompt states these criteria. A member that dispatches a subagent without promoting is promoted automatically at its first `subagent` tool call (pi's `tool_call` event), before the subagent starts.
3. One main per tab; an agent never takes over an existing main. With a live main in the tab, `boss_promote` is refused with a message and the automatic promotion is skipped. The member may still dispatch its own subagents, but first tells the main through intercom what it will do and which resources it will use (member prompt).
4. The workspace's first main opens the workspace tower at once (it used to open on demand). Later mains share it, and it stays open.
5. When the main's session ends, the tab has no main until some member promotes. A tab without a main gets the `member-no-main` prompt variant.
6. A main never demotes; it stays main until its session ends.
7. `/boss` stays the user's manual takeover: it makes this session the tab's main even when another is.
8. A promoted session's existing subagents count under it as main in the dashboard and the browser view, with no re-registration (they link through the launcher's session file, not its role; covered by a test).

Consequences: `boss_join` is replaced by `boss_promote`; `prompts/reminder.md` is gone; sessions saved with `asked: true` but not joined join on their next start, and no session entry is written for membership any more. Broadcast scopes keep their meaning; nearly every session is joined now.

## Mechanics

- Joining registers the session on the tab's intercom channel, owner-eligible, so the channel always has an owner. The owner records the main in the channel state (`{ main }`) but is not the main by being owner; a recorded main that is no longer a live session counts as no main.
- Promotion is a claim. The owner decides claims one at a time: a claim is dropped while another live main exists, unless forced by `/boss`. A claimer waits up to 5 s for the owner to confirm and then reports the refusal or the timeout.
- Tower opening goes through the existing guarded open (one at a time per workspace, a second tower in a workspace yields). A failure to open it is a warning; the promotion stands.
- Size budget: the "rest of src" budget in `tests/imports.test.ts` goes from 540 to 575 lines, for the claim, promotion, and automatic-join code that replaced the opt-in code in `src/index.ts`.
- Prompt budgets: `member.md` 80 words (it now carries the tell-the-main rule), new `member-no-main.md` 80.
