# pi-straw-boss 0.116.3

Released 2026-11-28. A patch release on [0.116.2](0.116.2.md).

## Fixed

- **A tower's viewer that closed stays closed until something waits for the boss.** Under headless runs, a plain `ensure-tower` (a promotion, a main's call) no longer opens a viewer for a tower whose viewer the idle close took, or that the boss ended. A card or a run still brings the viewer back, and the page's **Open viewer** still opens one. Before, an ensure that arrived just after an idle close opened a fresh viewer, and the idle close took it again half a minute later.
- 塔台關掉的 viewer，在有東西等老闆之前不會再開。headless runs 下，一般的 `ensure-tower`（升格、main 呼叫塔台）不會再替 viewer 已被閒置關閉、或老闆自己關掉的塔台開 viewer。有卡片或 run 時 viewer 照樣會回來，頁面上的 **Open viewer** 也照樣能開。先前閒置關閉後隨即來了一次 ensure，就會開出新的 viewer，半分鐘後又被閒置關閉收掉。
- **Straw Link's lock is never left empty.** `link/holder.lock` is now written whole or not at all: its text goes into a file of its own, which is then linked under the lock's name. A holder killed while it took the lock used to leave an empty lock file, and the next holder waited 10 s before it took over.
- Straw Link 的鎖不會再留下空檔。`link/holder.lock` 現在要嘛完整寫好、要嘛不存在：內容先寫進它自己的檔案，再用連結掛上鎖的名字。以前持有者在拿鎖途中被砍掉，會留下空的鎖檔，下一個持有者要等 10 秒才接手。
- **Test only.** More tests that failed only on a loaded machine now pass there. The standing pane's typing backoff, the boss conversation's 4 h cap and idle end, and the startup prune now run on clocks the tests move. The wrapper test signals its own run's pi, and the real-pi test gives pi the server's own grace to exit.
- 僅測試。又一批只在機器負載高時才失敗的測試，現在負載高時也會通過。常駐窗格的重打退避、老闆對話的 4 小時上限與閒置結束、啟動時的清理，改用測試自己推進的時鐘。wrapper 測試改成對它自己那個 run 的 pi 發訊號，真實 pi 的測試則給 pi 和 server 一樣的結束寬限時間。
