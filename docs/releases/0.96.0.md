# pi-straw-boss 0.96.0

Released 2026-11-26. A minor release on [0.95.0](0.95.0.md). Design record: [2026-11-26-device-hold.md](../specs/2026-11-26-device-hold.md).

## Added

- **Holding a teammate's box** (boss, 2026-11-26: 「sb 要處理接管模式下的變化」; rules 「照建議做」, start 「main 提出、你按同意」). A controller main asks with `link_request` `hold` (the boss approves; under auto mode it waits) or the boss runs `/boss link hold <device>`; `release` of one's own hold needs no dialog. The hold rides the controller's `board` (third field, caps `board.holds`; straw-relay unchanged) and is honoured by the box's own code only when the box is unattended and the sender is an attended member at `dispatch` in the box's policy. It lapses 30 minutes after the last board that carried it, at `--hours`, on revoke, or when the box's boss runs `/boss link held end` (the controller is told). While held, the box's mains are told once to finish what they hold and start no new work, their idle nudge, standing wake, revive and tower briefs say so, no `under` notice is raised for them, the free room goes to the holding main as `held-room` (with the box's `silent` and `quota`), and the box opens worker slips from the holder only. `board_read`, `/boss board` and the head page show the hold on both devices. Every teammate must run 0.96.0 before a hold can be set.
