# pi-straw-boss 0.81.6

Released 2026-11-21. A patch release on [0.81.5](0.81.5.md).

## Changes

- **`why: shared` is a heads-up, not a request for go.** A main that is about to change something outside its tab (a port, a database, a shared branch, a deploy target, a running service) tells the tower what and for how long with `reply: false`, then goes ahead at once. It stops only when the tower or the owner answers with a clash. The tower checks the board and its obligations and answers only on a clash, naming the owner; it no longer answers go or wait, and a main no longer waits 10 minutes before telling the boss. A car slip is unchanged: it still waits for sb's car notice.
