# pi-straw-boss 0.88.3

Released 2026-11-25. A patch release on [0.88.2](0.88.2.md).

## Fixed

- **An integrator with more than 256 cars reads the cars it acted on last.** `cars-read` kept the last 256 cars in the book's order, and a car keeps its place in that order when it gets a new state. A car forwarded long ago and received just now could fall outside the 256, so the train todo said it was never received. sb now keeps the 256 cars whose newest state is newest, still listed in the book's order.
