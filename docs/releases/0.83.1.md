# pi-straw-boss 0.83.1

Tagged 2026-11-23 but not published: the publish gate failed on the `src/net.ts` size budget. These fixes ship in [0.84.0](0.84.0.md).

## Fixed

- The morning ledger sweep no longer opens a tower to receive a leftover item. If the matching checkout has only an idle shell, the item goes on the head work board instead.
- When the GUI and a watch read the net at the same time, a late result can no longer report a backwards change or restart the watch's quiet or idle timer.
