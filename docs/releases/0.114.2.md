# pi-straw-boss 0.114.2

Released 2026-11-28. A patch release on [0.114.1](0.114.1.md).

## Fixed

- **Test only.** More tests that failed only on a loaded machine now pass there. The standing pane, desk and seat tests start the tower prompt as soon as its command is typed, as a shell does, or keep its launch wait for the whole case. The exit-wait tests let the prompt poll before the run starts, and a case that fails there now ends its test file instead of hanging it. The restart and start tests end the new server's boot gap after a count of the requester's touches, not after a fixed time. The boss-conversation test ends its event run with `tower_done`, and Herdr's deadline stand-in writes its pid before it does anything else.
- 僅測試。又一批只在機器負載高時才失敗的測試，現在負載高時也會通過。常駐 pane、desk 與 seat 測試在命令一打進去就啟動塔台提示，和 shell 的行為一樣，或讓啟動等待涵蓋整個案例。exit-wait 測試先讓提示輪詢一次再開始 run，案例在那裡失敗時，測試檔會結束，不再卡住。重啟與啟動測試在請求端更新記錄達到次數後才結束新伺服器的啟動空檔，不再等固定時間。boss 對話測試的事件 run 以 `tower_done` 結束；Herdr 截止時間的替身程式一開始就先寫下自己的 pid。
