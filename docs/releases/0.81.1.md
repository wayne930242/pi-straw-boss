# pi-straw-boss 0.81.1

Unreleased. A patch release on [0.81.0](0.81.0.md).

## Fixes

- **A turn before Straw Boss joins no longer pins an empty role section.** The first turn with a role pins the section and its tab and workspace labels.
- **A restored branch gets current role instructions.** If the branch already holds a role steer, a full steer supersedes it without rewriting the pinned section.
- **A tower run resends its brief after `/tree` followed by `/reload`.** The new branch gets the brief as a message even if no turn ran between the two commands.
