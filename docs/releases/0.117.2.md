# pi-straw-boss 0.117.2

Patch release on [0.117.1](0.117.1.md).

## Fixed

- A long-running pi session no longer passes a removed model to a child and triggers a “No models match pattern” warning.
  On launch and resume, the child inherits only models from the parent’s scope that are still registered and have authentication configured.
  If none qualify, the host refuses the request rather than allowing models outside that scope.
- 長時間開著的 pi 工作階段不再把已移除的模型傳給子代理，因而不會再出現該模型的「No models match pattern」警告。
  不論是啟動還是續跑，子代理只會繼承父工作階段原有範圍內、仍已註冊且設有驗證的模型。
  如果一個都不剩，宿主會拒絕這次請求，不會改用範圍以外的模型。
