# pi-straw-boss 0.81.2

Unreleased. A patch release on [0.81.1](0.81.1.md).

## Fixes

- **Early turns give Herdr labels time to arrive.** The role section waits for the tab and workspace labels it needs, then keeps them; if the labels never arrive, the section can pin after a short grace period.
- **Reloading a branch no longer repeats role instructions it already has.** The latest whole role steer is reused only while the model still sees it (compaction has not summarized it away) and it carries exactly the text that would be sent now, so an upgrade, a prompt edit, or a changed integration switch still reaches the agent; a steer from 0.81.1 or earlier is resent once. Tower digests do not count as role steers.
