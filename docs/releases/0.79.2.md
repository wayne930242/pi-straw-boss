# pi-straw-boss 0.79.2

Unreleased. A cleanup release on [0.79.1](0.79.1.md).

## Train

- **The merge-train contract has no legacy exception.** pi-anchorloop 2.16.3 declares `merge-train-contract: "1"` in its `integrating` and `deploying` skills, so Straw Boss no longer counts an undeclared skill inside pi-anchorloop 2.11.0 to 2.15.x as version 1 (`src/train/contract-legacy.ts` is gone). Install pi-anchorloop 2.16.3 or newer before this release; on an older one a train's and the integrator's changing calls are refused with the reason.

## Tests

- **The LAN pairing test no longer fails by chance.** It checked that the four-digit pairing number is nowhere in the log as a plain substring, so a year in a timestamp, a port or a pid could contain it; the v0.79.1 publish run failed once. It now looks for the number as a token of its own in the lines the pairing writes, whose facts hold no four-digit token, and still checks the whole log for the cookie.
