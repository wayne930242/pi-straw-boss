# pi-straw-boss 0.80.16

Released 2026-11-19. A fix release on [0.80.15](0.80.15.md).

## Fixes

- **A long `landed` or `received` check keeps its answer.** The server closed a control connection after 60 s with no traffic, even while a request on it was still being handled. Since 0.80.15 a base fetch may run for up to 10 minutes. A check of a large base (117 s) therefore lost its connection and `train_car` said "the sb server did not answer", although the check went on in the server. A connection with a request in flight is no longer idle; it closes 60 s after its last answer.

## Known limits

- A `train_car` retried while an earlier check of the same car is still fetching starts another fetch: the check at `received` runs outside the queue, and nothing joins two of them.
