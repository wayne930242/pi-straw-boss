# pi-straw-boss 0.94.0

Released 2026-11-26. A minor release on [0.93.0](0.93.0.md). Design record: [2026-11-26-ally-workers.md](../specs/2026-11-26-ally-workers.md).

## Added

- **Ally workers.** A controller main at `dispatch` trust starts a worker on a teammate's box with `call_tower({ message, worker: { device, branch, base?, model?, points?, label? } })` (boss, 2026-11-26: 「照建議全部做」). The box's server opens a main of kind `worker` in its own worktree (`~/.herdr/worktrees/<repo>/<branch>`), on a model from `config.json` `workers.models`, admitted against `capacity.budget` with the declared points (0.25 to 10, default 1). The worker counts on the box's capacity row and board, and its final `call_tower` `why: milestone` goes back by code to the asking main as one `link_reply`. A refused or failed open, a crash, or 60 minutes idle with no report (nudged at 15) is answered by a code receipt. A revoke interrupts it. The ask lives 7 days. The box lists `tower.worker` in its caps only with a wait router, a `workers` section and a budget; straw-relay is unchanged.
- **Route caps** for opened mains are 24 per device and 40 in all; a live row is never trimmed, and a worker open at the cap is refused.

## Fixed

- **The ask an opened main's route takes gets no end-of-run receipt.** Before, the box answered that ask with its code receipt when the ally run ended, so the opened main's real report reached an ally run on the asking computer instead of the main that asked.
