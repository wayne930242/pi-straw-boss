# pi-straw-boss 0.95.0

Released 2026-11-26. A minor release on [0.94.0](0.94.0.md). Design record: [2026-11-26-event-ledger.md](../specs/2026-11-26-event-ledger.md).

## Added

- **Event ledger.** sb appends one line per event to `~/.pi/agent/straw-boss/ledger/<UTC day>.jsonl` (mode 600) and never prunes it, so a reader such as pi-evals can tell later where a work item waited and on whom (boss, 2026-11-26: 「先重建，再補小欄位」). Kinds: `wait_raised`, `wait_parked`, `wait_answered` (`by`: terminal, gui, phone, box, tower), `wait_closed` (`why`: resolved, dropped — ended without an answer), `wait_returned`, `link_wait_open`, `link_wait_done`, `thread_open`, `thread_close` (done, blocked, abandoned), `call_tower` (milestone, shared, blocked), `wrap` (wrapped, auto, refused), `handover`. A line holds ids, kinds and times only, never message, question, note or summary text. A failed write never fails the act; it is warned about once.
- **`boss_pair` `item`.** A review thread can name the work item it serves (a pi-todo-ledger `uid`, or `<session8>#<id>`); `T<n>.json` keeps `item`, and `closed` with `closedAs` once the thread closes.
- **Box controller door.** A press from a box controller reaches the tower memory as `box`, apart from `phone`.

## Changed

- `boss_pair`'s description is shorter, to keep the tools budget.
