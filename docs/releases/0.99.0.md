# pi-straw-boss 0.99.0

Released 2026-11-26. A minor release on [0.98.0](0.98.0.md). Design record: [2026-11-26-ally-workers](../specs/2026-11-26-ally-workers.md), section Resume.

## Added

- **Resume an ally worker by its session.** `call_tower` `worker: { device, resume: "<session id>" }` reopens a worker on the teammate's box in its own pi session (`pi --session <file>`), in its kept worktree or one rebuilt from `origin/<branch>`, with the message as its follow-up. The worker's final report and the box's gone and idle receipts end with a code-written `Session: <uuid> · resume: …` line, and the box keeps each worker's record 7 days after its last end. Only the device that opened the worker, through the same workspace, at `dispatch`, may resume it; the open's checks (settings, model allowlist, capacity, hold) run again. Every refusal answers the ask with its cause: no record, still running or closing, session file or folder mismatch, branch gone, model not allowed, no room, held by another device. The controller refuses before sending when the box lacks the new caps feature `tower.worker.resume`.

## Changed

- **`caps` lists `hello` first, and new builds read up to 32 features.** An older build cuts after 16 and still finds `hello` and every feature it knows. The operate `open` message keeps 16, so its signed body is unchanged.
- **A tower shows `working` while it answers a teammate.** The stand-in counts a live ally run that is not idle, as it counts a local run; worker mains do not count, they have their own row.
