# pi-straw-boss 0.102.0

Released 2026-11-26. A minor release on [0.101.0](0.101.0.md).

## Added

- **`call_peer`: a member reaches its tab's main through sb.** `call_peer {to: "main", message, ask?}` finds the tab's main when it is called, from the broker's record, so a message sent after a handover or a rotation reaches the successor instead of a remembered, stale id. It goes under the usual header (`kind=call_peer`); `ask: true` stamps `reply=expected`, and the answer comes back as an intercom message. A tab with no main refuses it and names `boss_promote`. `main` is the one target for now; the selector leaves room for other peers. Only a member has the tool in its active set (about 290 characters); a main, a train, a tower, and a subagent carry none of it, and a call from any of them is refused.

## Changed

- **`prompts/member.md` points to `call_peer`** before a member dispatches a subagent or asks about a shared resource, and drops the `board_read` lookup plus intercom (884 to 844 bytes).
