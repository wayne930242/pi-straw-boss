# pi-straw-boss 0.86.0

Released 2026-11-24. A minor release on [0.85.1](0.85.1.md).

## Added

- **Capacity on the board.** A capacity row shows where there is room for more work. Notices distinguish unused capacity from stale reports, quota limits, and a device that has gone silent. Escalations call attention to conditions that need intervention.

## Changed

- **Dispatch follows the device budget.** `capacity.budget` caps the number of workers on a device. Integrators group ready cars into batches of two or three.
- **Todo-ledger support.** sb reads pi-todo-ledger’s `todo/v1` contract and `todo:guard`, with a fallback for projects using rpiv.
