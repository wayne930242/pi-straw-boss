# pi-straw-boss 0.80.1

Released 2026-11-14. A fix release on [0.80.0](0.80.0.md).

## Train

- **A car of an app that is a git submodule can show delta evidence.** An evidence entry with a `delta` names an `on.head` that must be an ancestor of the car's head, and git was asked in the project's root, where a submodule's commits do not exist: the integrator's `train` todo refused the car with `evidence entry 1: on.head is not the car's head`, `train check --accept` said the same, and the yard and the train's board showed the car as unverified. Git is now asked in the app's own repository: the app's `dir` of `apps.json` when that folder holds a `.git` of its own, in the checkout the session or the command runs in, and in the main checkout of the project when that one is a linked worktree. An app whose folder is part of the project's repository is checked where it was.
 The folder must stay inside the project after symlinks are resolved, and a `.git` file must name a git dir inside the project's repository, so no `apps.json` entry leads git outside the project.

## Known limits

- An app whose `dir` is a folder inside a submodule, not the submodule's root, is still checked in the project's root.
- The server's received and landed checks of a car still fetch the app's base from the project's remote, where a submodule app's commits do not exist. It is not reached today: a car is received unchecked when the server's git has no credential, and no project sets `landed` yet.
