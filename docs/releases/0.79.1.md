# pi-straw-boss 0.79.1

Released 2026-11-13. A fix release on [0.79.0](0.79.0.md): the review findings parked at 0.77.3 and 0.79.0, and one decision of the boss.

## Train cars

- **An unchecked receipt names the remote's host.** When sb cannot reach a project's remote to check a slip, it still receives the car unchecked (the rule stays), and the notice now says which host it tried: "could not reach the project's remote at <host>". Only the host is shown, never a user, password, token, port, or path; a remote sb cannot parse as a URL is not named.
- **A slip header is split where the slip starts.** `openingFacts` splits the opening at an `app: … | car:` or `tickets:` slip start, as the train role does, so a slip line such as `base:` is no longer read as the header's (R0773-F004).
- **The integrator door says how to add words of your own.** A slip ends at a blank line; text after a slip goes after one. The door still refuses an unknown `key: value` line inside a slip (R0773-F003).

## Net and kinds

- **An `integrator` claim needs integration on.** A main opened with the integrator duty in its pane token records `integrator` only while integration is on; otherwise it is a coordinator (R0790-F003).
- **A resume script still being written is read again.** sb no longer keeps a resume index built while a script did not yet name its child (R0790-D001).

## Herdr and robot_hand

- **A Herdr read is retried after a reset socket.** ECONNRESET, EPIPE, and ECONNREFUSED retry a read once, like a closed connection; a write is still sent once (R0773-F002).
- **"Check again" after a lost acknowledgement of a page Cancel** of robot_hand reports the bridge's own accepted answer, not "dismissed in the terminal" (RC-F002). A test covers auto mode with a cancellable robot_hand (RC-F004).

## Parked

Review P3s, none blocking: a resume script that never names its child keeps the index off for its folder (stats only); a refused Herdr socket costs a read 250 ms before it fails.
