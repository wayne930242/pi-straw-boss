# pi-straw-boss 0.80.7

Released 2026-11-16. A fix release on [0.80.6](0.80.6.md).

## Briefs and roles

- **A main's and a member's role section names no other session** (95ff6241). The section is the same bytes for every session of its kind.
- **A head run's brief is a message** (7f9fbefd). The run's system section is the same bytes for every run, and the brief comes as a message that opens with `[brief from the sb server]`, at the start of the first turn that has not had it.
- **The integrator exemption covers only claiming a pre-dev branch** (e3b05900). No main merges to base.
- **No unsolicited turn after a compaction.** A head run is given its brief again behind a compaction's summary. At the end of a turn the compaction ran while pi was still streaming, so the message queued and pi started a model turn nobody asked for. It is now stored without a turn, and steered in only when the compaction retries one. A test runs a real threshold compaction and counts the model calls, and another holds that no event opens with the brief marker.

## Known limits

- A member and a member without a main flip state in the section of a role that does not name them; the flip reaches them as a message only.
- A local tower run is not given the live brief as a message.
- A resident tower's digest stays in its section.
- Each memory write gives the head run another brief, so the conversation grows with them.
- After a threshold compaction between tool rounds of a running head turn, the brief is stored at the next turn end, so one model call relies on the summary's copy of it.
