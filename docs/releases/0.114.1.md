# pi-straw-boss 0.114.1

Released 2026-11-28. A patch release on [0.114.0](0.114.0.md).

## Changed

- **The done nudge costs less in each child.** Every child of sb's subagent host checks for a reminder request every 2 seconds. An idle check is now one `stat` of the run's folder, and the folder is listed only when its mtime moved. With 10 children an idle check takes about 2 µs per child, down from 4 to 14 µs in 0.114.0. The parent already touched no file for a child that is not due a reminder. See the [spec](../specs/2026-11-28-done-nudge.md).
- 完成提醒在每個子代理裡更省資源。sb 子代理宿主的每個子代理每 2 秒檢查一次有沒有提醒請求。現在閒置時的檢查只對這個 run 的資料夾做一次 `stat`，資料夾的 mtime 變了才列出內容。10 個子代理時，每個子代理一次閒置檢查約 2 µs，0.114.0 是 4 到 14 µs。父 session 對還不到提醒時間的子代理，本來就不碰任何檔案。
