# pi-straw-boss 0.111.3

Released 2026-11-28. A patch release on [0.111.2](0.111.2.md).

## Fixed

- **A tower's pane no longer lingers.** A workspace tower's standing pane now closes once the tower has been idle for 30 seconds with no card waiting for you: no run or ally run live, no event waiting to wake one, no wake due. Only the pane closes; Herdr drops the emptied tab. The tower itself stays: its identity, its token, its queue and its memory, so mains reach it as before. The next run, ally run, card, or `ensure-tower` (a bare `/boss tower`, a promotion) makes the tab again as the first open did, so a card that opens shows its `N cards wait` row. `/boss tower <message>` and the page reach a tower with no pane. The pane stays while it is its workspace's last pane, shares its tab with a split of yours, was taken with Ctrl+D, holds a pi you started there, or holds words on the prompt's line. The head tower keeps its pane: it is its workspace's only pane. See [When the pane closes](../how-it-works.md#when-the-pane-closes).
- 塔台的 pane 不再一直留著。工作區塔台的常駐 pane，在塔台閒置 30 秒、又沒有卡片等你時就會關掉：沒有執行中的 run 或隊友 run、沒有等著喚醒 run 的事件，也沒有到期的喚醒。只關 pane，分頁空了由 Herdr 自己拿掉。塔台本身留著：身分、token、佇列與記憶都在，主智慧體照舊找得到它。下一次 run、隊友 run、卡片或 `ensure-tower`（單獨的 `/boss tower`、升任）會照第一次開啟的方式重建分頁，所以新開的卡片會顯示它的 `N cards wait` 那一列。`/boss tower <message>` 和頁面也找得到沒有 pane 的塔台。pane 是工作區最後一個 pane、和你自己的分割共用分頁、被你用 Ctrl+D 接手、裡面跑著你自己開的 pi，或提示的輸入列上還有字時，都會留著。主塔台保留它的 pane：那是它工作區唯一的 pane。
