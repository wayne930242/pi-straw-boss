# pi-straw-boss 0.90.0

Released 2026-11-25. A minor release on [0.89.0](0.89.0.md). Design record: [2026-11-25-idle-wrap-up.md](../specs/2026-11-25-idle-wrap-up.md).

## Added

- **An idle main is asked whether its work is done.** A main of kind coordinator or integrator that has been idle 30 minutes gets one nudge from its own session: continue or clean stale todos if work remains, stop if it waits on someone other than the boss, or wrap up if it is done. One nudge per idle period; none under auto mode (the clock restarts when it ends), none while a dialog, monitor, loop, `boss_watch`, subagent, or queued message is open. Standing mains, members, trains, towers, and mains opened for a teammate's device are never nudged.
- **`boss_wrap`.** A main that is done calls it with a summary. It refuses while any todo is open or anything of the session still runs, under auto mode, in a teammate's remote turn, and for the kinds above. Otherwise it asks the boss in the main's own pane (the pane shows as waiting, and the dialog is relayed like any other); on Yes it checks again, sends the tower a `milestone` with the summary (and the opener session the same summary), clears the board, and closes the pane, the tab with it when emptied. No closes nothing, and no nudge follows until the main works again.

## Changed

- **A main asks the boss itself.** With auto mode off, a decision only the boss can make is asked by the main with `ask_user_question` in its own pane, so the boss sees which agent asks; `call_tower` `blocked` is for waits on anyone else. Under auto mode the ask is refused and the main calls `blocked` as before: the tower parks the card, and it returns to the main as `wait_returned` when auto mode ends. A tower run with no auto mode line tells a local main to ask the boss itself instead of recording a card; the tower's own questions, a train's, and a teammate device's still become cards.
- `main.md`'s done rule now ends with a daily memory entry (when a memory tool exists) and `boss_wrap`.
