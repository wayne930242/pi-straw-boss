# pi-straw-boss 0.82.1

Unreleased. A patch release on [0.82.0](0.82.0.md).

## The tower closes agent panes

- **A main that handed over is closed by its tower.** The boss asked on 2026-11-23: 「tower agent 應該也要有能力把 agent 的 pane 用 herdr cli 關閉，特別是交接以後」. Until now a main that rotated with `boss_handover` stepped down and waited, and only the boss could close it when he had opened it. `boss_close_main {main}` now closes a main whose role record says it handed over, whoever opened it and whatever its kind, once its successor is live (the broker lists it and pi runs in its pane). The old main still runs its own check, so a turn, a queued message, a dialog, a monitor, or a subagent still refuses the close. A live main the boss opened that did not hand over, and a standing main that did not, are refused with the same words as before. This also shortens the known limit RVR-F007 of 0.82.0: a tower-opened main's successor counts against its sender's cap beside the old main only until the tower closes the old one.
- **The tower hears of the handover.** When the successor takes the handoff, the old main sends its workspace's tower a `call_tower` milestone that names both sessions and the successor's tab, and the `boss_handover` result tells the old main that its tower closes it.
- **Dead agent panes.** `boss_close_main` with no argument lists the agent panes of the tower's workspace whose pi is gone: Straw Boss or pi-herdr-agents marks, no session in the broker, and `herdr pane process-info` showing a bare shell. `boss_close_main {pane}` closes one, and its tab when it was the tab's only pane. It covers mains, members, trains, and the panes subagents left behind. Never a live pi, a tower's pane, another workspace's pane, or a pane an open, a revive, or a handover is starting. A tower run has the same tool through the sb server; an ally run is refused `pane` and the list.
- `tower.md` and `tower-run.md` tell the tower to close the old main once its successor is live and to close the dead agent panes it finds.
- Design: [tower-close-panes](../specs/2026-11-23-tower-close-panes.md). Guide: [Closing a main that handed over, and a dead agent pane](../how-it-works.md#closing-a-main-that-handed-over-and-a-dead-agent-pane).
