# pi-straw-boss 0.78.0

Released 2026-11-13. A feature release on [0.77.3](0.77.3.md).

## The head tower runs the overnight watch (issue #16)

While auto mode is on, the sb server reads the net every 15 minutes and wakes the head tower when the reading holds something new. A wait refused or cancelled, a dialog waiting, a parked wait, a main idle at two readings with open work, a tower in trouble, a stuck train, an unanswered forward of the head, a stall, or a workspace with no output for 2 hours. It reads output (board lines, car notices), not pane activity. A calm reading wakes nobody. The head acts with its existing tools (`tower_send`, `tower_memory`, `board_read`, `tower_list`) and decides nothing past the boss's mandate. Spec: [2026-11-12-auto-watch.md](../specs/2026-11-12-auto-watch.md).

- **Switching auto mode on opens the head tower** when none is open. A head that closes later in the night is not reopened; the readings without it are counted for the morning.
- **One notice at a time, told only when taken.** A notice counts as told only when a head run that took it ended well; a notice lost, purged or parked leaves its findings for the next notice and the morning. After two parked notices in a row the watch stops sending and says so in the morning. Switching auto mode off drops the watch's notices no run holds. The notice lifecycle is modeled and checked ([docs/models/auto-watch/](../models/auto-watch/README.md), rules W1 to W6).
- **The morning.** The return list (`/boss auto off`, `auto/report`) gains the watch: readings, calm ones, wakes, nudges the head made, quiet workspaces, and every finding of the night in one place (taken by a run in flight, parked, told to nobody, or still open at the last reading). The GUI's return panel does not draw it yet.
- Every word a session wrote that the notice quotes is stripped of control characters, cut, quoted, and withheld when it looks like a secret.
