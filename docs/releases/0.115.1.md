# pi-straw-boss 0.115.1

Released 2026-11-28. A patch release on [0.115.0](0.115.0.md).

## Fixed

- **GUI.** No card wears a border on one side only any more; a card that stood out by a coloured left or top edge now carries its colour on a border all around or in its fill. In the Raven theme, the double gold line along a panel's top became a thin gold-grey 1px border on all four sides, as the boss chose.
- GUI。卡片不再只有單邊框；原本靠左側或上方色邊凸顯的卡片，改以四邊框線或底色帶出顏色。Raven 主題面板頂端的金色雙線，依 boss 的選擇改為四邊金灰色 1px 細框。
