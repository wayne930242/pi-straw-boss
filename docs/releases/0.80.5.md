# pi-straw-boss 0.80.5

Released 2026-11-16. A fix release on [0.80.4](0.80.4.md).

## Prompt audit

Wording fixes from an audit of the prompts, role pack, and model-facing strings. No behavior changes.

- **`call_tower`'s `message` no longer says "at most two sentences".** Car slips and `train:` manifests already go through it whole; the description now says so.
- **`boss_rename` states the real limits:** the tab label is cut at 16 characters, a name over 40 is refused.
- **`tower-run.md`:** the card language is "the language your brief names" (the Tools block names it, not the Memory section); the line about re-recording an `old free-text wait` is gone, since the row itself carries that instruction.
- **Tool-agnostic "no questions"** replaces the named `ask_user` in `tower.md`, `tower-run.md`, and `ally-run.md`.
- **Migration-relative wording removed** from `integrator.md` ("queued before 0.65.0", "still list the old uat stage") and `apps-config.md` ("today's flow").
- **`head-run.md`:** the one-or-two-lines ceiling on what the head tells the boss is now "briefly".
- **`roles/scout.md`:** inherited Principles and Approach sections and a repeated sentence about the final message are dropped.
- **`roles/planner.md`:** the plan opens with `show_doc` when the user is to confirm it, not after.

## Known limits

Audit findings that need an owner decision are not applied: the legacy-train clause of `integrator.md`, the worker and brief `caller_ping` wording, and the system-section rewrites mid-session.
