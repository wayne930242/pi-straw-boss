# pi-straw-boss 0.81.3

Unreleased. A patch release on [0.81.2](0.81.2.md).

## Fixes

- **A main an ally run opened can wait on the device that opened it.** Its `call_tower` with `why: blocked` and `waitsOn` used to reach that device's ally runs, which forward no wait, so it arrived as a plain message, the other end could only escalate it, and the answer came back as a new incident instead of reaching the main. The sb server now forwards such a wait itself, as a tower run forwards a local main's: with the wait field and the main's ask, recorded in the workspace's ledger, so each step and the answer reach the main. Nothing of it enters a run here. A wait on any other device is refused with a message that says which device opened the main.
- **Mains have `board_read`.** A main told of a teammate's wait (`kind=link_wait`) is sent to `board_read` section `waits`, which only towers had. Every main now has it, with the waits of its own workspace in both directions; a remote turn sees what it saw before.
