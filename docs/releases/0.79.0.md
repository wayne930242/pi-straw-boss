## Agent kinds, phase 2: the net knows every kind

[Spec](../specs/2026-11-09-agent-kinds.md), Phase 2 steps 1 to 4.

- **A subagent keeps its kind when it is resumed.** Each pi-herdr-agents child now records its role in its own session file at its first turn (a `straw-boss { agent }` entry, written once). The net reads the kind from that entry (the first one in the first 64 KB), and the launch script stands in before the first turn. A resumed child gets a new id and a launch script with no role. The net now finds it by the script that carries its id, then by that script's session file and the pane that runs it. A running resumed child therefore shows with its name, its live mark, and its kind. Before, it showed as `done` under a hex id. It keeps its kind when another session resumed it, too.
- **`boss_open_main` takes `duty`.** `duty: "standing"` opens a main of kind standing; the default is coordinator. The new pi consumes the kind with its one-time claim. It writes the kind entry and keeps the kind in its role record, so a Herdr restore before its first message brings it back with its kind. An integrator is still opened only through `role: "integrator"`, whose door now hands the new pi its kind directly instead of relying on the name `integ <project>`. A train takes no duty.
- **`boss_status` and `tower_list` show each main's kind** (`kind` beside the tab's main; null for a tab with no main).
- **A standing main's board line is never stale.** It minds one system with no end, so `board_read`, the tower's brief, and the page no longer mark its old line as stale.
