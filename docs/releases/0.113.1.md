# pi-straw-boss 0.113.1

Released 2026-11-28. A patch release on [0.113.0](0.113.0.md).

## Fixed

- **The documentation site updates again.** The Pages build had failed since 0.107.0, so the site still showed 0.106.0. Twice, the zh-TW translation of [How it works](../how-it-works.md) was marked on a branch that was then rebased, so it named an English commit main never had, and the translation check stopped on it. The translation now names the matching commit on main. The check reports such a commit instead of crashing, and `npm test` fails on one before a push.
- 文件網站恢復更新。Pages 建置從 0.107.0 起一直失敗，網站停在 0.106.0。[運作方式](../how-it-works.zh-TW.md)的繁中譯本兩度在之後 rebase 的分支上標記，標示的英文 commit 因此不在 main 上，翻譯檢查在那裡中斷。譯本現在標示 main 上對應的 commit；檢查遇到這種 commit 會說明，不再當掉，`npm test` 也會在推送前擋下。
- **Test only.** Three tests that failed only under a loaded machine now pass there: the pane balance's wait for a closed pane reads a clock the test moves, the seat tests start the tower prompt as soon as its command is typed, as a shell does, and the `group: false` deadline case reads its facts from the child the cut leaves alone.
- 僅測試。三個只在機器負載高時才失敗的測試，現在負載高時也會通過：pane 平衡等候 pane 關閉時，改讀測試自己推進的時鐘；seat 測試在命令一打進去就啟動塔台提示，和 shell 的行為一樣；`group: false` 的截止時間案例，改從截斷時不受影響的子行程讀取資料。
