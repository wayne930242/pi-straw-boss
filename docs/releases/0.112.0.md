# pi-straw-boss 0.112.0

Released 2026-11-28. A minor release on [0.111.3](0.111.3.md).

## Added

- **Questions waiting on you.** Every open question to the boss is now recorded as an Ask, so you can see who waits on you and where. `call_tower`'s boss question is a blocking Ask: the first valid answer wins, whether you give it in the pane, on this computer's page, or on a paired phone, and the others close. The questions sb only sees (towers' wait cards, the head tower's included, a teammate's wait, units waiting on `ask_user_question` or `ask_user`) are mirrored without taking them from their owners. Each Ask is bound to the todo it blocks. A unit's plate shows a gold pill with its count, the head and workspace pages list them, and in pi `/boss asks` prints the same with the todo each blocks. pi-todo-ledger can read the rows through `straw-boss:ask-rows:v1`. An answer the store never confirmed is not treated as yours: the asker is told so and does not act on it, and the page keeps its recheck button. See [Questions waiting on you](../how-it-works.md#questions-waiting-on-you).
- 等你回答的問題。現在每一個給老闆的未答問題都會記成一筆 Ask，你看得到誰在等你、在哪裡等。`call_tower` 的老闆提問是阻塞式的 Ask：第一個有效答案勝出，不論你是在 pane、這台電腦的頁面，還是配對的手機上回答，其餘的就關掉。sb 只看得到的問題（塔台的等待卡片，含主塔台的、隊友的等待、在 `ask_user_question` 或 `ask_user` 上等待的單位）會鏡像成 Ask，但不從原主手上拿走。每筆 Ask 綁到它擋住的 todo。單位的牌子上有金色小標顯示數量，主塔台與工作區頁面列出清單，pi 裡的 `/boss asks` 也印出同樣內容並附上各自擋住的 todo。pi-todo-ledger 可以透過 `straw-boss:ask-rows:v1` 讀這些列。紀錄端沒確認的答案不算你的答案：提問方會被告知、不會照做，頁面也保留重新確認的按鈕。
