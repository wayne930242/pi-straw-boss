# pi-straw-boss 0.100.0

Released 2026-11-26. A minor release on [0.99.0](0.99.0.md). Design record: [2026-11-26-storybook-theme](../specs/2026-11-26-storybook-theme/spec.md), section B11.

## Added

- **Storybook's chat page is one notebook page.** The log has ruled lines, a red margin line, binding holes, and washi tape across the top edge. Tool calls are small label stickers. Each message carries its speaker's woodcut animal as a stamp: you are the bunny, a main its kind's beaver, and a subagent's report its kind's bee (the notice's sender is looked up by name, Storybook only). A corner picture is drawn for the current phase only: by day the bunny reads under the apple tree, by night it dozes with a lantern. While the session works, a bee drifts above the composer. Calm, reduced motion, and forced colours keep it still.

## Changed

- **Storybook's birds and crickets play about 10 dB quieter**, at Raven's rain level (a mean near −42 dBFS before the Background volume). The first build was louder than the spec meant.
