# pi-straw-boss 0.80.15

Released 2026-11-19. A fix release on [0.80.13](0.80.13.md). 0.80.14 was tagged but never published: its publish run failed a source size budget.

## Fixes

- **A large base no longer times out a car's `landed` or `received` check.** The server fetches the base's branch into a fresh mirror for each check, and every git command it ran had 60 s. A 135 MB base took 117 s to fetch, so `train_car landed` was refused four times for one car, the integrator's call too, and the car's fate stayed unrecorded. The fetch now gets 10 minutes; every other git command keeps 60 s. `train_car` waits up to 15 minutes for the server's answer, enough for an `ls-remote` and a full fetch.
- **A finger resting on the GUI log no longer flashes "N new".** A finger on a log that followed its end, or the 250 ms coast after it, held the log and counted arriving entries as unseen. Only selected text counts them now; a touch still holds the log where it is.

## Known limits

- Each check still fetches the whole base branch into a new mirror, and `landed` checks are taken one at a time, so several cars of a large project landing at once wait for each other's fetches.
