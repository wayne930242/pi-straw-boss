# pi-straw-boss 0.88.1

Released 2026-11-25. A patch release on [0.88.0](0.88.0.md).

## Changed

- **The tower says it closes on its own.** Once the boss types in a tower run's pi, its footer says how long the run waits for their silence before it wraps up and closes by itself, and that `/quit` ends it now. The minutes come from the server; the line clears when the boss's four hours in the run are spent or the run leaves. See [The boss in a run](../how-it-works.md#the-boss-in-a-run).
