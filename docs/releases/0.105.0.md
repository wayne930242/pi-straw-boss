# pi-straw-boss 0.105.0

Released 2026-11-26. A minor release on [0.104.0](0.104.0.md). It completes the GUI theme contract (`docs/specs/2026-11-26-theme-contract/spec.md`, now implemented); see [Themes](../how-it-works.md#themes).

## Changed

- **Storybook paints less.** The traced pencil frame, the paper grain and the dividers are day and night PNGs instead of SVG images (with `feTurbulence`), and the five live status masks (pencil, envelope, flag, moon, stars) are 96 px PNG masks. Their keyframes did not change. On a ticking map, Storybook's pre-paints in a 10 s trace are within three times Standard's (10→13, 12→14, 11→11), and no pre-paint happens inside an image any more.
- **Raven's error text stays readable through the lightning.** Card error text uses Raven's soft crimson; offline, stale and unreachable cards that show an error or a monitor line, or a retained tower error notice, are no longer dimmed as a whole (the dashed edge, the offline wording and the stale mark stay); the auto-mode refusal in the toolbar gets Raven's dark well while it has text. Every measured place is at least 4.78:1 on desktop and 4.96:1 on a phone at the bolt and candle peak (it was as low as 1.01:1).
- **Contract v1 additions**: classes `au-crash`, `role`, `au-word`, `auto-sw-note`, `error` and attributes `data-tone`, `data-monitoring`, `data-trust`, each with its GUI writer. Nothing was removed or renamed.

## Tooling

- **`npm run budgets`** and `tests/budgets.json`: each theme folder and the eager page, lazy chunks and stylesheet have a design ceiling and a recorded figure; a test fails above the ceiling or above the recorded figure plus 1 % or 2,048 bytes. Raven and Storybook have 512,000 bytes. Hash noise no longer rewrites caps.
- **`scripts/paint-trace.mjs`** measures the spec's paint rule, pausing every non-theme animation (pseudo-elements and late transitions too) and running Chrome with `NavigationPredictor` off for both faces, since its link sampling puts any page with links into a 60 Hz style-recalc state.
- **The style matrix is deterministic**: route data and paint settle before capture, so a phase gate passes in one run with no per-cell retry.
- The Raven contrast guard reads the winning declaration (importance, `@media` context, source order).
