# pi-straw-boss 0.113.2

Released 2026-11-28. A patch release on [0.113.1](0.113.1.md).

## Fixed

- **A headless tower's viewer closes when nothing waits for you.** With `towerRuns.headless: true`, a tower's viewer tab now closes by the same rule as a standing pane: once the tower has been idle for 30 seconds with no card waiting for you, no run or ally run live, no event waiting to wake one, and no wake due. Before, 0.111.3 closed only standing panes, so on a computer with headless runs no viewer ever closed. Only the pane closes and the tower goes on as before. A viewer closed this way comes back as a fresh viewer when a card of the tower opens, or before a run or an ally run starts, on an attended computer only; an unattended box never opens one. A viewer you ended yourself does not come back, and a viewer that cannot be made again does not hold a run back. The head tower's viewer and the last pane of a workspace stay. See [The service and its viewer](../how-it-works.md#headless-runs).
- 無介面塔台的 viewer 在沒有東西等你時會關掉。`towerRuns.headless: true` 時，塔台的 viewer 分頁現在和常駐 pane 依同一條規則關閉：塔台閒置 30 秒、又沒有卡片等你、沒有執行中的 run 或隊友 run、沒有等著喚醒 run 的事件，也沒有到期的喚醒。先前 0.111.3 只關常駐 pane，所以開著無介面 run 的電腦上，viewer 從來不會關。只關 pane，塔台照舊運作。這樣關掉的 viewer，會在塔台有卡片開啟時，或在 run 或隊友 run 啟動之前，以新的 viewer 回來，而且只在有人值守的電腦上；無人值守的盒子從不開 viewer。你自己結束的 viewer 不會回來，viewer 重開不成時也不會擋住 run。主塔台的 viewer 和工作區的最後一個 pane 都會留著。
