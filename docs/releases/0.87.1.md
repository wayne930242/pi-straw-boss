# pi-straw-boss 0.87.1

Released 2026-11-24. A patch release on [0.87.0](0.87.0.md).

## Changed

- **Stale notices leave waiting work alone.** A main is not stale while it has a running monitor, an armed loop, or an sb watch. A todo can say it waits: `metadata.until` (an ISO date or time) or `metadata.waitsOn` (who it waits for). Until then it counts neither toward stale nor as ready work, so it pulls no under-capacity notice. A main whose open todos all wait is not stale. Both fields stay in the local ledger; nothing new crosses the link.
- **One stale notice per spell.** A main is told once while it stays stale, also across a server restart; the next notice comes only after it has moved and gone stale again.
- **Planning prompt.** It names the two fields and says that a running monitor, loop, or `boss_watch` keeps a main from going stale.
