# pi-straw-boss 0.80.0

Unreleased. A feature release on [0.79.2](0.79.2.md).

## Agent kinds, phase 3: the watchdog

[Spec](../specs/2026-11-09-agent-kinds.md) §10, Phase 3. See [The watchdog](../how-it-works.md#the-watchdog).

sb ships a seventh role, `watchdog`: a subagent that watches one unit of the net (a main with its monitors and todos, a train, another subagent) and tells the session that dispatched it what goes wrong. It can only read and report.

- **The role.** `roles/watchdog.md` lists three tools, `read`, `watch_read`, and `watch_report`, sets `thinking: low`, and names no model. It is sb's own file, derived from neither source of the other roles (`NOTICE.md`).
- **`watch_read`** waits for one unit to change. It is a long poll on the sb server that answers `changed` (the unit's mark, a monitor's status or exit code, todo progress, a train's step, or a subagent's mark moved), `stalled` (no activity for the `quietMs` the task names), `load` (a monitor's load over `loadMax`), `unchanged`, `expired` (the task's `deadline` passed), or `gone`, with the unit's state and the time. Output lines and notes wake nothing, so a quiet target costs six turns an hour at the default wait of ten minutes. The reply holds no transcript and no path.
- **`watch_report`** sends one finding to the dispatcher and to nobody else: the tool has no recipient parameter. The message arrives under a header with `kind=watch_report` and `from=watchdog <child name>`. A watchdog sends at most one report every 30 s and never the same text twice in a row.
- **The sb server answers both** on its control socket (`watch-read`, `watch-report`). It holds a read for at most 45 s and judges on the GUI's readings of the net; with the GUI stopped it reads the net itself every 10 s, only while a read is held. Before it sends a report it ties the caller to a watchdog and to its dispatcher by pi-herdr-agents' own files: the activity file, a launch or resume script, and the role the child's session file records.
- **sb holds the boundary.** For a watchdog, every tool call outside `read`, `watch_read`, `watch_report`, `caller_ping`, and `subagent_done` is blocked with `sb: a watchdog only reads and reports`, whatever tool list a spawn or a resume passed. This holds outside Herdr too, for a child that pi-herdr-agents' Core backend launched. A child is a watchdog by its role name (at launch, or in its session file after a resume), never by its tool list. In any other child the two tools are inactive and nothing is blocked.
- **A watchdog that cannot watch says so.** One whose spawn passed a tool list without the watch tools reports `sb: watchdog <name> cannot start: …` to its dispatcher and ends, before its first turn.

## A coordinator dispatches a watchdog without a plan

The dispatch gate now passes `watchdog` beside `scout`, `planner`, and `reviewer`: a coordinator whose todos name no graph may dispatch one at once, and the `sb: plan first` refusal of a worker names it among what may run now. A standing main's prompt now reads "Watch with `MonitorCreate` or a `watchdog` subagent, not by checking in your own turns." Integrators and standing mains were never gated, and nothing new is refused.

## To move

- **The sb server.** A watchdog needs an sb server of 0.80.0 or newer; a main's `/reload` upgrades a running one. Against an older server `watch_read` answers `unchanged` with `server: "outdated"` and keeps waiting, and `watch_report` fails with a message that says the server is older.
- **The model is yours to set, per machine.** The role names none, so a watchdog runs on whatever that machine's pi-herdr-agents configuration gives the role (`models.agents.watchdog` in `~/.pi/agent/herdr-agents/config.json`), else on its default. The server computes the verdicts, and by the spec's estimate a watchdog wakes 6 to 30 times an hour on a small context, so a small model fits.
- **Role names.** `/boss roles-check` now lists seven roles, and counts `watch_read` and `watch_report` among the names only a subagent has. A global or project role named `watchdog` still wins over the pack's; sb holds a child of that name to the same five tools.
- **A main older than 0.80.0** that receives a report reads it as plain text under an unknown `kind`.
