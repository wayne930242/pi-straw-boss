# pi-straw-boss 0.77.2

Released 2026-11-12. A hotfix of [0.77.1](0.77.1.md).

## Fixes

- **A car of a private remote is received again.** 0.77.1's check at `received` (issue #15) refused every car whose project's remote needs credentials, such as a private `https` GitLab: "git ls-remote of develop from the project's remote failed: fatal: could not read Username … terminal prompts disabled". The server runs that check with git of its own, which by design reads no global configuration and so has no credential helper, and it turned any failure of git into a refusal.

  Now, when `ls-remote` or the fetch fails because the remote cannot be reached or authenticated (credentials, a terminal prompt, the connection, or a repository not found), the car is received unchecked: the integrator's tool says `Received unchecked:` with the reason, and the server logs `cars-received-unchecked` with its class (`auth`, `connection`, `repository-not-found`). A head already on the base, a mirror written to by something else, a tip that moved between `ls-remote` and the fetch, an app with no usable `integration.base`, and any other git failure are still refused. `landed` is unchanged, and git's isolation is unchanged.
