# pi-straw-boss 0.113.0

Released 2026-11-28. A minor release on [0.112.0](0.112.0.md).

## Changed

- **A quieter tower.** A tower no longer starts a run for every `call_tower`. sb records each `milestone` and `shared` call in the tower's logbook and wakes a run only when it has work: a milestone from a main the tower opened or a session it asked, a heads-up that clashes with another session's open heads-up or with the board of another main in the sender's workspace, a car slip or train manifest, `blocked`, and everything else that woke before. A heads-up that clashes with nothing gets "recorded, no clash seen" without waking its sender. A woken run's brief lists the logbook entries no run has read, and `board_read` section `logbook` and `/boss board log` show the book. Replaying the event runs of 2026-11-26 and 27 through the new gate, 67 of 141 runs still start (48% of the runs, 52% fewer); before, every one of the 243 calls woke a run. See [The logbook](../how-it-works.md#the-logbook) and the [spec](../specs/2026-11-28-tower-quiet.md).
- 更安靜的塔台。塔台不再為每一則 `call_tower` 開一個 run。sb 把每一則 `milestone` 與 `shared` 呼叫記進塔台的帳本，只在有事做時才喚醒 run：塔台開的 main 或它詢問過的 session 送來的里程碑、和其他 session 仍有效的報備或寄件者工作區裡其他 main 的看板撞到的報備、車廂單或火車清單、`blocked`，以及其他先前就會喚醒的訊息。沒撞到任何東西的報備會收到「已記錄，未見衝突」，不喚醒寄件者。被喚醒的 run 的簡報會列出還沒有 run 讀過的帳本條目，`board_read` 的 `logbook` 區段與 `/boss board log` 也能查帳。把 2026-11-26 與 27 的事件 run 重放過新閘門，141 個 run 只剩 67 個會啟動（剩 48%，少 52%）；先前 243 則呼叫每一則都喚醒一個 run。
