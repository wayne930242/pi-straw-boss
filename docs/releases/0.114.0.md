# pi-straw-boss 0.114.0

Released 2026-11-28. A minor release on [0.113.2](0.113.2.md).

## Added

- **A worker idle too long is asked to finish.** When a child of sb's subagent host has ended its turn and sat 10 minutes without delivering a result, sb asks it, in its own session, to write its final report and call `subagent_done`, or to use `caller_ping` if it truly waits on its caller. It asks once per idle stretch and twice in all, then tells the parent once in a `Subagent status` line. The question goes through the child's own pi, and only when the child is idle and its input box holds no unsent text, so a draft the user is typing there is never sent. An auto-exit child is never asked, because a fresh turn would close it and deliver its unfinished work as done; its parent is told instead. Interactive children, persistent specialists, a child whose turn runs or that is blocked, and one being cancelled are never asked. `subagentNudge` in `~/.pi/agent/straw-boss/config.json` sets it (`{ "idleMinutes": 10, "max": 2 }`; `idleMinutes: 0` turns it off). A `/reload` revokes the open requests and keeps the counts, and a notice for the parent stays queued until pi has taken it into the parent's session. See [The subagent host](../how-it-works.md#the-subagent-host) and the [spec](../specs/2026-11-28-done-nudge.md).
- 閒置太久的 worker 會被請去收尾。sb 子代理宿主的子代理結束回合後，閒置 10 分鐘還沒交回結果時，sb 會在它自己的 session 裡請它寫好最終報告再呼叫 `subagent_done`；它若真的在等呼叫端，就用 `caller_ping` 說明。每段閒置問一次，總共兩次，之後在 `Subagent status` 那一行告訴父 session 一次。提醒經由子代理自己的 pi 送出，而且只在子代理閒著、輸入框裡沒有未送出的文字時才送，所以使用者正在輸入框裡打的草稿絕不會被送出。自動結束的子代理一律不問，因為新的一回合會讓它關閉，把沒做完的工作當成完成交回；改由父 session 收到通知。互動式子代理、常駐專家、回合還在跑或卡住的子代理，以及正在取消的子代理，一律不問。設定在 `~/.pi/agent/straw-boss/config.json` 的 `subagentNudge`（`{ "idleMinutes": 10, "max": 2 }`；`idleMinutes: 0` 關掉）。`/reload` 會撤回還沒處理的請求，次數會留著；給父 session 的通知要等 pi 把它收進父 session 才離開佇列。
