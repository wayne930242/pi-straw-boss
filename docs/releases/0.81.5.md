# pi-straw-boss 0.81.5

Unreleased. A patch release on [0.81.4](0.81.4.md).

## Fixes

- **Tower runs can now refer to an event they received.** The first line shows the queue ID separately from the sender's session ID, so a tower can forward a teammate wait with `tower_send` or a car slip with `tower_reply`.
  If `waitsOn.event` does not match, the refusal lists the wait event IDs this run received so it can retry.
