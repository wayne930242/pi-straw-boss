# pi-straw-boss 0.101.0

Released 2026-11-26. A minor release on [0.100.2](0.100.2.md). Design record: [2026-11-26-plan-graph-jit](../specs/2026-11-26-plan-graph-jit.md). Needs pi-todo-ledger 0.4.0 for the todo's `graph` field.

## Added

- **A main that plans without a graph is told how, at that moment.** When a coordinator or standing main creates todos and none of its open todos names a graph, that `todo` result carries planning.md's sections on naming the graph and writing the plan, condensed (about 1.2 KB), ending "Set the `graph` field on these todos." It comes once, and once more only after the main's open todos named a graph and then again named none. main.md does not grow. Members, workers, integrators, trains, and towers never get it.

## Changed

- **The plan's graph is the todo's own `graph` field** (pi-todo-ledger 0.4.0). planning.md asks for it instead of `metadata.graph`; the page and the new hint still read a legacy `metadata.graph`.
