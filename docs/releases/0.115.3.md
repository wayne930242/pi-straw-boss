# pi-straw-boss 0.115.3

Released 2026-11-28. A patch release on [0.115.2](0.115.2.md).

## Fixed

- Role updates in pi's terminal now show one line with the role, kind and line count. Use the expand-tools shortcut (Ctrl+O by default) to read the full message. The model still receives the full instructions.
- 角色更新在 pi 終端機只顯示一行，列出角色、分工和行數。按展開工具輸出的快捷鍵（預設 Ctrl+O）即可讀取全文；模型收到的仍是完整指示。
- Compaction no longer sends the same role instructions again when the system section still supplies them. Reloading no longer repeats a matching signed update just because it was summarized away. A role change still reaches the model. The coordinator prompt is shorter; the instructions for writing a worker brief now live in `planning.md`.
- 如果系統區段裡已有相同的角色指示，壓縮對話後就不再重送。重新載入時，用簽章核對過、內容相同的更新即使已被摘要掉，也不會再貼一次。角色真的改變時仍會通知模型。協調員的提示詞也縮短了，派工簡報的寫法改放在 `planning.md`。
