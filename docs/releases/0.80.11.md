# pi-straw-boss 0.80.11

Released 2026-11-18. A feature release on [0.80.10](0.80.10.md).

## Changes

- **sb puts each car's slip into the train's manifest.** When the integrator calls the tower `why=shared` with a `train:` manifest, sb appends the slip of every car on that code's `train` todo, verbatim from the tower's forward of its head. A slip already in the message stays when it matches. Nothing is sent, with a word naming what to fix, when the code has no train todo, a car has no forward, a slip in the message names a head not on the todo or differs from its forward, or a car ended before the train opens. A manifest that only named slip files by path left the train unable to set any car's fate (train 2026-11-17-q).
- **A train finds a car that its manifest text lacks** among the cars the sb server holds for it, received for its code.
- **The integrator can end a car it received once that car's train is gone:** `dropped` (round, reason, evidence), `returned` (reason), or `landed` (version, commit; the same git check against the open's base and remote as a train's, refused when this server did not record the open). Whether the train is live is read from its Herdr pane and session; when either cannot be read, the end is refused. A car already ended is not ended again. The integrator waits for these notices as it does for a return at receipt.
- **`train_car` takes `app` and `head`.** A ticket on two cars (one ticket in two apps) is refused without them, listing each car's app and head.
- An integrator end whose tower forward expired (24 hours, or 512 newer forwards) says so and how to get the slip sent again.

## Known limits

- A train whose pi crashed keeps its pane's train tokens until they lapse; until then the integrator cannot end its cars. Close the train's pane to free them.
- A train's shell can rewrite its own pane's tokens and so let the integrator end that train's cars; this ends rides only and gives no merge right.
- The car book stays in the server's memory: a server restart forgets received cars, as before.
