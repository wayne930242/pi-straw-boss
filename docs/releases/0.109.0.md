# pi-straw-boss 0.109.0

Released 2026-11-27. A minor release on [0.108.0](0.108.0.md).

## Added

- **The plan view.** A main's todo list that carries a plan (a dependency, an owner, a defer, or a graph name) is drawn as steps by dependency, each todo with its state in words, its owner, what it comes after, and what it waits on until when. The head page's work board draws it for each main's automatic entry, and the session page's todo box draws it with the whole checklist folded under it, so finished tasks, points, anchors, and the last run stay a tap away. An owner the net has links to its session and has **Focus**; one that left the net reads gone. The plan stays on this computer: teammates get none of it. See [The work board](../how-it-works.md#the-work-board).
- **`/boss send #<id>` or a todo uid** writes to the owner of that todo of this session's list: the Herdr child the todo is bound to, or the one subagent under this main whose exact name it is. A name cut on the board, a box's todo, or two subagents of one name reach nobody. A subagent also answers to its full launch name.

## Fixed

- A todo whose blockers were more than 50 kept only the first 50, so one still open past them no longer held it: the plan showed it ready and the capacity count took it as ready work. The open blockers are now kept before the cap.
- The tower prompt's last poll, on its way when the boss pressed Ctrl+D, could reach the server after the leave. The server took it for a prompt the boss had started, ended the park, and typed the prompt's command into the boss's shell. A poll from the prompt that left now ends no park.
- Two tests that failed under heavy load: the restart's touch test took its stall allowance from a worker thread, which the OS keeps running while the busy main thread waits, and now also times the requester's own waits; a Windows start test counted the starts of the next run, which begins 40 ms after the crash, and now counts the starts of its own run.
