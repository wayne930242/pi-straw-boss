# pi-straw-boss 0.117.1

A patch release on [0.117.0](0.117.0.md).

## Fixed

- `/boss tower` opens and focuses the workspace viewer even after it has closed for inactivity. From a linked worktree, it focuses the parent’s tower only if one already exists. `/boss tower <message>` still sends the message without changing focus.
- `/boss tower` 會重新開啟因閒置而關閉的塔台分頁，並切換到該分頁。從連結的工作樹執行時，只能查看上層工作區已有的塔台。`/boss tower <訊息>` 仍只傳訊息，不切換分頁。
- Straw Link can take its lock on filesystems that cannot create hard links. Failure to delete a temporary file no longer cancels a successful lock acquisition. A later caller removes leftover lock files only after the process that made them has exited.
- 在不支援硬連結的檔案系統上，Straw Link 也能取得鎖。刪除暫存檔失敗不會影響已取得的鎖；下次取鎖時，只會清除建立行程已結束的鎖暫存檔。
