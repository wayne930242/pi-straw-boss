## Wi-Fi access: the GUI on your phone over the local network

`/boss gui lan` lets a phone on the same Wi-Fi as the computer open the GUI without Tailscale.
It is off by default and listens only on private IPv4 addresses of this computer, on port 8445.

- The sb server makes its own certificate authority, after showing you the risk and recommending your phone's hotspot or a direct Wi-Fi.
  Each phone installs the certificate once, so the page is HTTPS and the installed app works.
  The computer's screen tells you how to check what the phone installed (exactly one certificate, with the SHA-256 shown).
- Pairing is by QR code or a typed code, as with remote access, plus approval on the computer: you type the number the phone shows.
- A Wi-Fi device may do what a paired tailnet device may do.
- New: `/boss gui lan`, `/boss gui lan off`, `/boss gui lan reset`; the Phone tile gets a Tailscale tab and a Same Wi-Fi tab; `cli.mjs status` has `lan`; `cli.mjs up` can warn `lan_off`.
- New files in the state directory: `lan.json`, `lan-ca.json`, `lan-ca-files/`.
- Firewall notes: macOS and Windows are read without elevation and the note says what to change; the page words them in English and Traditional Chinese, keeps the commands verbatim, and marks only the notes that block access as errors.
- The Same Wi-Fi tab offers one download link for each certificate file, and a request that waits shows a notice in the page's header while the tab is closed.
- `/boss gui rotate` also unpairs Wi-Fi devices and keeps the certificate.
- Straw Link, Tailscale access, and desk mode are unchanged; the Phone tile still does not show in a desk window.

Details: [how it works](../how-it-works.md#browser-view), design: [the spec](../specs/2026-10-30-sb-gui-lan.md).
