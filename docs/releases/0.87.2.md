# pi-straw-boss 0.87.2

Released 2026-11-24. A patch release on [0.87.1](0.87.1.md).

## Changed

- **No worker cap by count.** sb no longer holds a main to 4 running workers. On an attended device (the boss's own, who watches it) nothing holds a worker back, with or without a `capacity.budget`; the budget there feeds only the board, the supply tray, and the capacity notices.
- **An unattended device caps workers by points, from config.** A worker starts while the device's points in use, the launches it does not count yet, and the worker's own weight fit `capacity.budget` in config.json. Its weight is the `metadata.points` of the todo it owns (1 without one; 0.25 is allowed for a light, API-bound worker). The budget is read at each launch, so a change applies without a restart, and sb has no built-in figure: no budget, no cap. A main the device row does not list, or any main while no fresh row exists, also reserves device-wide and counts its own running workers.
- **Main prompt.** Mains dispatch ready work in parallel; on an unattended device, within its capacity budget.
