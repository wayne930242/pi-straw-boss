# pi-straw-boss 0.110.0

Released 2026-11-27. A minor release on [0.109.3](0.109.3.md).

## Added

- **sb hosts subagents itself.** A plain `pi install npm:pi-straw-boss` now brings dispatch: `subagent`, `subagent_cancel`, `subagent_resume`, `subagents_list` and `/subagent`, under the names and parameters pi-herdr-agents used, so prompts and skills need no change. sb runs them on the Maestro engine (`@nubl/maestro` 0e1dd78) in a simple mode: each worker runs one task in a Herdr split pane, exits, and its result comes back as a message. Persistent specialists, `subagent_interrupt`, managed worktrees, `accept` checks, Herdr Core, the sidebar plugin and the task-model writer are left out; a call that passes `persistent`, `notify`, `worktree` or `accept` is refused with what to do instead. The models come from `<agent dir>/herdr-agents/config.json`, the file pi-herdr-agents read, so `task:coding` and the rest keep working. The operating guide ships as the skill `pi-straw-boss-subagents`. See [The subagent host](../how-it-works.md#the-subagent-host).
- sb 現在自己當子代理的宿主。一般的 `pi install npm:pi-straw-boss` 就會帶來派工：`subagent`、`subagent_cancel`、`subagent_resume`、`subagents_list` 與 `/subagent`，名稱和參數都沿用 pi-herdr-agents，prompt 和 skill 不必改。sb 以 Maestro 引擎（`@nubl/maestro` 0e1dd78）的簡單模式執行：每個 worker 在 Herdr 分割窗格跑一件任務，做完就結束，結果以訊息送回。常駐專員、`subagent_interrupt`、受管 worktree、`accept` 檢查、Herdr Core、側欄外掛與任務模型寫入器都不納入；帶 `persistent`、`notify`、`worktree` 或 `accept` 的呼叫會被拒絕，並說明改用什麼做法。模型設定讀 `<agent dir>/herdr-agents/config.json`，也就是 pi-herdr-agents 讀的檔，所以 `task:coding` 等照常可用。操作指南以 skill `pi-straw-boss-subagents` 隨附。
- **Any session can dispatch, with or without a todo.** A main, a member, a train, or a session that never joined launches the same way, and a worker launched without `item` (a quick scout, a check off the plan) is a normal worker: nothing warns of it. In pi, workers reach pi-todo-ledger through `pi-herdr-agents:run-rows:v1`, unchanged, which draws a worker under its todo or in its group of other workers; the rows no ledger claims show in a small Subagents box, one row each: name · model · state · time. In the GUI, a session outside the tabs now shows the workers it launched under it, as a main does.
- 任何 session 都能派工，有沒有 todo 都可以。main、member、train 或從沒加入網的 session 用同樣的方式派工；沒帶 `item` 派出的 worker（臨時的 scout、計畫外的檢查）是一般的 worker，不會有任何警告。在 pi 裡，worker 透過不變的 `pi-herdr-agents:run-rows:v1` 交給 pi-todo-ledger，畫在它的 todo 底下或「其他 worker」群組；沒有被 ledger 認領的列，顯示在小小的 Subagents 方框，一個 worker 一列：名稱 · 模型 · 狀態 · 時間。在 GUI 裡，分頁以外的 session 現在也會把它派出的 worker 顯示在自己底下，和 main 一樣。
- **One host.** sb's host registers at session start, after every extension has, and reads pi's own record of who registered `subagent`. With pi-herdr-agents (or another copy of pi-straw-boss) loaded, sb's host stands down, registers nothing, and says so once; `sb_doctor` and `/boss doctor` show the host as active, stood down (and why), off, or failed, with the Maestro commit from the lock. Load order is never consulted. `<agent dir>/straw-boss/host.json` `{ "host": "off" }` turns the host off.
- 只有一個宿主。sb 的宿主在 session 開始時、所有擴充都註冊完後才註冊，並讀 pi 自己的紀錄看是誰註冊了 `subagent`。若載入了 pi-herdr-agents（或另一份 pi-straw-boss），sb 的宿主會退讓，什麼都不註冊，只說一次；`sb_doctor` 與 `/boss doctor` 會顯示宿主是啟用、退讓（及原因）、關閉或載入失敗，並附上 lock 裡的 Maestro commit。不看載入順序。`<agent dir>/straw-boss/host.json` 寫 `{ "host": "off" }` 可關閉宿主。

## Changed

- **A worker lost is told once, and nothing else.** When a worker of sb's host loses its pane or its pi before it reports, its failed result carries one paragraph with its name, session file and the `subagent_resume` call. sb's revive, pick-up, orphan nudge and restore paths stand aside for these runs; they keep serving pi-herdr-agents' runs where it is the host.
- worker 失聯時只告知一次，其他什麼都不做。sb 宿主的 worker 在回報前失去窗格或 pi 時，它的失敗結果會附上一段，寫出名稱、session 檔與 `subagent_resume` 的呼叫方式。sb 的復活、接手、孤兒催報與還原機制對這些 run 一律讓開；在 pi-herdr-agents 當宿主的地方，它們照舊服務 pi-herdr-agents 的 run。
- The sb server still needs pi-intercom, which a plain install does not bring: `sb_doctor` says so, and that the host works without it.
- sb server 仍需要 pi-intercom，一般安裝不會帶它：`sb_doctor` 會說明這點，也會說明宿主沒有它也能運作。
