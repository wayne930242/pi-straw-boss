# pi-straw-boss 0.116.1

Released 2026-11-28. A patch on [0.116.0](0.116.0.md).

## Changed

- `subagents_list` now shows authenticated models and configured task-category shortlists alongside the available roles. These lists no longer take up space in the prompt on every turn. Straw Boss's other tool descriptions are shorter; the arguments and actions still work the same way.
- `subagents_list` 現在會在可用角色旁列出已驗證的模型，以及各任務類別設定的候選模型。這兩份清單不再佔用每一輪的提示空間。Straw Boss 其他工具的說明也縮短了，參數和操作方式不變。
