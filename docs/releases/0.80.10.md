# pi-straw-boss 0.80.10

Released 2026-11-17. A feature release on [0.80.9](0.80.9.md).

## Changes

- **A tower with wait cards for you shows as waiting in Herdr.** The stand-in on its standing pane is reported `blocked` while cards wait (open, not pressed), with `2 cards wait` first in its message; the head's stand-in counts every tower's cards and its own. With none it is idle again. An unattended device keeps it idle, and auto mode leaves it blocked, since the parked cards still wait.
- **sb has a language setting.** `locale` in `~/.pi/agent/straw-boss/config.json` (`"zh-TW"` or `"en"`) wins over `LC_ALL`, `LC_MESSAGES`, and `LANG` for the sb server, the tower prompt, a run's cards, and the `/boss` commands. `/boss locale` shows it, and `/boss locale zh-TW`, `en`, or `auto` sets it. Cards already written keep their language.
- **The stand-in's message follows that language:** `待命中`, `3 則待處理`, `已擱置`, `2 張卡片等你` in Traditional Chinese.
- **`/boss locale` keeps a symlinked `config.json`:** the file it points to is updated, and its mode stays (it was cut to a plain file with mode 600).

## Known limits

- `/boss locale` does not take the Straw Link lock (that lock belongs to the link holder's process); it reads and renames in one synchronous step, so only a write of another process in that instant is lost.
- A tower prompt that is already up keeps its language until it starts again (after the next run), and a pi session's `boss_wait_ask` keeps the language of its start.
- The setting has no control on the page; set it with `/boss locale` or in `config.json`.
