# pi-straw-boss 0.97.0

Released 2026-11-26.

## Changed

- **A tower's Herdr state follows one order** (boss 2026-11-26: 「只有有 wait 票要處理的時候才應該是 waiting herdr state，處理完應該是 finished」). The stand-in is `blocked` only while wait cards wait for the boss, `working` while a run of the tower handles something (an event run, a conversation turn), and `idle` otherwise; Herdr shows `done` by itself after the work until the boss looks at the pane. One pure function, `src/server/standin.ts`, decides it at every look.

## Fixed

- **A stale `blocked` on a tower with no cards.** Under headless runs the tower prompt stays in the pane while a run works, but the server reported nothing during a run, so a `blocked` from cards answered meanwhile stayed for hours. The state is now reported during runs too.
