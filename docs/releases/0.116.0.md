# pi-straw-boss 0.116.0

Released 2026-11-28. A minor release on [0.115.3](0.115.3.md).

## Added

- **A launch's todo is checked before it starts.** A `subagent` or `boss_pair` call with `item` has that todo looked at first, from the raw `todo/v1` snapshot of the launcher's branch. A `blockedBy` cycle the todo still waits on refuses the call and names the cycle, since that todo can never become ready. A missing anchor, an anchor that names no runnable check (such as `tests pass`), a deleted or unknown blocker, and an item that names no todo of the list only warn, in one line on the call's result. `boss_pair` checks before it opens the thread, so a refused pair opens none. See [The subagent host](../how-it-works.md#the-subagent-host) and the [spec](../specs/2026-11-28-todo-preflight.md).
- 派工前會先檢查它的 todo。帶 `item` 的 `subagent` 或 `boss_pair` 呼叫，會先讀派工者分支上原始的 `todo/v1` 快照，看那一個 todo。那個 todo 仍在等待的 `blockedBy` 有循環時，呼叫會被拒絕並寫出循環，因為那個 todo 永遠不會就緒。沒有 anchor、anchor 沒有指出可以執行的檢查（例如 `tests pass`）、blocker 已刪除或不存在，以及 item 指不到清單裡的 todo，都只在呼叫結果上加一行警告。`boss_pair` 在開串之前檢查，被拒絕就不會開串。

## Fixed

- A defer whose `until` has passed no longer shows as waiting on the board and the session page; a defer with `waitsOn` still waits for it. `metadata.until` is read as pi-todo-ledger reads it, so an impossible day (`2099-02-30`), a space or a lowercase `t` before the time, or hour 24 marks no wait.
- `until` 已經過了的延後，在看板與 session 頁上不再顯示為等待中；有 `waitsOn` 的延後仍等它。`metadata.until` 的讀法與 pi-todo-ledger 相同，所以不存在的日期（`2099-02-30`）、時間前用空白或小寫 `t`、或 24 時，都不算等待。

## Performance

- The check's CPU median is at most 5 ms a launch on a 5,000-row ledger with up to 12 blockers a todo. It is a median, not a bound on every launch: with every row open, the p95 ran near 22 ms on this Mac under load.
- 在 5,000 列、每個 todo 最多 12 個 blocker 的帳本上，這項檢查每次派工的 CPU 時間中位數不超過 5 毫秒。這是中位數，不是每次的上限：每一列都未完成時，這台 Mac 在高負載下的 p95 約 22 毫秒。
