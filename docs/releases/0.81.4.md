# pi-straw-boss 0.81.4

Unreleased. A patch release on [0.81.3](0.81.3.md).

## Fixes

- **Two standing mains with the same name can both be told about the same link wait.** When a main declares itself standing or renames itself while standing, the tool warns if another live standing main in the same workspace has that name.
  The warning names the other session and explains how to finish a handoff or rename one of the sessions; it does not demote either main or change how waits are routed.
