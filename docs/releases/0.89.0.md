# pi-straw-boss 0.89.0

Released 2026-11-25. A minor release on [0.88.3](0.88.3.md).

## Added

- **A main's handover carries its todo list.** `boss_handover` writes the main's todo list, ids, anchors, evidence, and metadata included, to `<handoff>.todos.json` beside the handoff file, leaving out deleted tasks and the dependencies on them. The successor's first prompt tells it to restore the list with `todo` `import` (pi-todo-ledger 0.2.0 or newer) instead of recreating it from the handoff text; with an older ledger, or when the import is refused, it recreates the todos from the handoff as before. An empty list, an invalid one, or a failed write leaves no file and still opens the successor, and the tool's result says why.

## Changed

- **The `sb-train` guard judges imported lists.** It registers with `imports: true` and checks every task an import would commit: a train refuses any import; a main other than an integrator cannot import a task that carries `metadata.sb`; an integrator's imported train todos pass the same step, contract, claim, and acceptance-evidence checks as created ones.
- **A teammate's remote turn imports a todo file only from inside the project.** `todo` with `action: "import"` is checked like `read`: an allowed file in the project passes, any other path goes to the confirm, and a denied path is refused. Other `todo` actions stay free.
