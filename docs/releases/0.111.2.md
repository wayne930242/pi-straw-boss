# pi-straw-boss 0.111.2

Patch release after [0.111.1](0.111.1.md).

If pi-herdr-agents is still handling subagents, Straw Boss now warns once at session start and shows where pi loaded the old host and how to remove it. Run the `pi remove` command shown, then `/reload`. Without a UI, the warning goes to stderr. Nothing is removed automatically.

若 pi 仍由 pi-herdr-agents 派出子代理，Straw Boss 會在工作階段開始時提醒一次，列出舊套件的載入路徑和移除指令。執行畫面上的 `pi remove` 指令，再執行 `/reload`。沒有互動介面時，提醒會寫到 stderr。Straw Boss 不會自行移除套件。
