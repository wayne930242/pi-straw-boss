## Changes

- **A car from another computer cannot authorize its own deploy.** A car slip forwarded with `origin=remote:<device>` is written by that device's main, so its `auth` is a peer's words, not the boss's. The integrator prompt now says such a car's `auth` covers no `strict` target unless it quotes the boss of this computer, and the integrator returns it naming the target otherwise (review R151-F006, boss decision 2026-11-12).
