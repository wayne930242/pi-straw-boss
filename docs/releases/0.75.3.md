# pi-straw-boss 0.75.3

Not yet released.

## Changes

- **A car from another computer cannot authorize its own deploy.** A car slip forwarded with `origin=remote:<device>` is written by that device's main, so its `auth` is a peer's words, not the boss's. The integrator prompt now says such a car's `auth` covers only the `strict` targets its device's boss granted, quoted, and for any other target the integrator asks the boss through the tower (`why=blocked`) (review R151-F006, boss decision 2026-11-12).
