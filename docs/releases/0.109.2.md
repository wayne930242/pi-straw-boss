# pi-straw-boss 0.109.2

Released 2026-11-27. A patch release on [0.109.1](0.109.1.md).

## Fixed

- A folded wait from a teammate device now says what the device is waiting for. Previously the row began with “Press done” and explained the buttons without showing the request. Open the card to read the instructions. Alerts use the same subject, and it stays visible when the snapshot leaves out the full card.
- 隊友裝置送來的等待卡收合時，現在會顯示對方在等什麼，不必展開才看得到。原本列表只說明何時該按「完成」或「婉拒」；現在展開卡片才會看到按鈕說明。通知也會顯示請求內容，即使快照因大小限制省略完整卡片，摘要仍會保留。
